# Guild Legends — les actions de guilde (10 nov. 2026, demande de Théo)
# Ce que le maître ou la maîtresse peut organiser pour le repère : repas, jeux, concours, sorties, travaux…
# Certaines sont gratuites et immédiates, d'autres coûtent cher ou demandent plusieurs heures (ou jours) de préparation.
#
# Format : id|catégorie|titre|coût|préparation (heures)|ton|effets|récit
#   coût : en PO au palier Inconnue ; il est multiplié aux paliers suivants (actions.js).
#   ton : la façon dont les héros jugent le geste (maitre.js) : genereux, complice, ferme, juste, ecoute, compatissant, laxiste.
#   effets, pour chaque héros présent : m = moral (souvenir de 2 jours), s = envie de voir du monde, l = détente,
#           e = envie de progresser, n = énergie ; r = réputation de la guilde (une fois).
# Jetons du récit : {un}, {deux} (deux héros présents), {chien}, {bourg}. Aucun accord de genre sur un héros.
# Écrits à la main. Le français d'un message qu'on enverrait pour raconter la soirée.
