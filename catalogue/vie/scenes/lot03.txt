# Après le retour de Théo (« trop génériques, on ne se sent pas dedans »), ce lot ancre les scènes dans CETTE guilde :
#   - la mémoire : ce qui vient d'arriver (mission, blessure, dispute, arrivée, soirée, fugue) ;
#   - la voix : les héros parlent, avec leurs propres mots ({a:situation}) ;
