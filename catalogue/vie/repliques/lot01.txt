# Répliques des héros · lot 1 (8 nov. 2026)
# Ce que disent les héros dans les scènes : {a:taquine} dans une scène est remplacé par une réplique de a pour la situation « taquine ».
# Format : Qui|situation|réplique, guillemets compris. Qui = un champion, ou « registre:xxx » pour la voix commune d'un registre de lettre
# (noble, rue, sage, brut, joyeux, sombre, singulier). La réplique d'un champion passe avant celle de son registre.
# Situations : salut, taquine, console, vante, plainte, merci, accueil, colere, rire, excuse.
# {b} peut apparaître dans une réplique : c'est l'autre héros de la scène. Les répliques de registre n'ont aucun accord de genre ;
# celles d'un champion peuvent accorder pour le champion lui-même, jamais pour {b}.
